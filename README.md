# MSI Limited - Tech Portfolio Website

Modern, high-performance single-page portfolio website for MSI (Digital Engineering & Experience Studio).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)

### Running Locally
Run the built-in HTTP server:
```bash
node server.js
```

Then open your browser and navigate to:
```
http://localhost:3000
```

## 📂 Project Structure

- `index.html` - Primary portfolio landing page
- `server.js` - Local static development server
- `msi_single_page_portfolio_1/` - Single-page portfolio variation 1 (with screenshot preview)
- `msi_single_page_portfolio_2/` - Single-page portfolio variation 2
- `obsidian_kinetic/DESIGN.md` - Design system, colors, and typography specifications
